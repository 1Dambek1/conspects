
## 1. Что такое ветка?

Ветка — это как отдельная «линия времени» твоего кода.  
Например:

- `main` (или `master`) — основная стабильная версия.
    
- `feature/login` — ветка, где ты делаешь авторизацию.
    
- `bugfix/navbar` — ветка для исправления багов.
    

---

## 2. Основные команды

### 🔹 Посмотреть все ветки

```bash
git branch
```

Звёздочкой отмечена текущая ветка.

### 🔹 Создать новую ветку

```bash
git branch feature/login
```

### 🔹 Переключиться на ветку

```bash
git checkout feature/login
```

или новой командой:

```bash
git switch feature/login
```

### 🔹 Создать и сразу перейти

```bash
git checkout -b feature/login
```

### 🔹 Слить ветку с другой

Допустим, ты закончил ветку `feature/login` и хочешь влить её в `main`:

```bash
git checkout main
git merge feature/login
```

### 🔹 Удалить ветку

```bash
git branch -d feature/login
```

---

## 3. Поток работы (workflow)

1. Всегда работаешь на новой ветке для каждой задачи.
    
    ```bash
    git checkout -b feature/registration
    ```
    
2. Делаешь коммиты и пушишь изменения.
    
    ```bash
    git add .
    git commit -m "Добавил регистрацию"
    git push origin feature/registration
    ```
    
3. После проверки (например, через Pull Request) вливаешь ветку в `main`.
    
4. Удаляешь ненужную ветку.
    

---

## 4. Зачем это нужно?

- **Безопасность**: ты не сломаешь основную ветку.
    
- **Параллельная работа**: несколько человек могут работать над разными задачами.
    
- **История**: легко откатиться или понять, кто и что сделал.
    

## 🔹 1. Удаление локальной ветки

Если ветка тебе больше не нужна на твоём ПК:

```bash
git branch -d имя_ветки
```

Например:

```bash
git branch -d feature/login
```

⚠️ Если Git ругается, что ветка ещё не влита (и ты уверен, что можно удалить), используй:

```bash
git branch -D feature/login
```

---

## 🔹 2. Удаление ветки в удалённом репозитории (например, GitHub)

Для этого нужно “запушить” удаление:

```bash
git push origin --delete имя_ветки
```

Пример:

```bash
git push origin --delete feature/login
```

После этого ветка исчезнет с GitHub.

---

## 🔹 3. Через интерфейс GitHub

1. Открой репозиторий на GitHub.
    
2. Перейди во вкладку **Branches**.
    
3. Найди ветку и нажми на корзинку (Delete).
