## **1. Что такое Docker?**

Docker — это инструмент для контейнеризации, который позволяет разрабатывать, упаковывать и запускать приложения в изолированных средах (контейнерах).

### **🔹 Основные преимущества Docker:**

✅ **Изоляция:** Каждое приложение работает в отдельном контейнере, что предотвращает конфликты между зависимостями.  
✅ **Легковесность:** Контейнеры используют общее ядро операционной системы, а не создают отдельные виртуальные машины.  
✅ **Повторяемость:** Код запускается одинаково на любом сервере, независимо от операционной системы.  
✅ **Быстрое развертывание:** Запуск контейнера занимает считанные секунды.  
✅ **Гибкость:** Контейнеры легко масштабируются и управляются.

## **2. Установка Docker на Windows**

1. **Скачать Docker Desktop** с [официального сайта](https://www.docker.com/products/docker-desktop/).
2. **Установить** (важно: для Windows 10/11 Home потребуется WSL2).
3. **Перезагрузить ПК и запустить Docker Desktop**.
4. **Проверить установку:**
    
    ```sh
    docker --version
    ```
    
5. **Запустить тестовый контейнер:**
    
    ```sh
    docker run hello-world
    ```
    
    Если установка успешна, появится сообщение с подтверждением работы Docker.

## **3. Основные понятия в Docker**

| Термин                    | Описание                                                                                 |
| ------------------------- | ---------------------------------------------------------------------------------------- |
| **Образ (Image)**         | Шаблон, содержащий все необходимое для работы приложения (код, библиотеки, зависимости). |
| **Контейнер (Container)** | Запущенный экземпляр образа, который можно запускать, останавливать и удалять.           |
| **Dockerfile**            | Файл, описывающий процесс сборки образа.                                                 |
| **Volume**                | Механизм хранения данных за пределами контейнера.                                        |
| **Network**               | Виртуальная сеть, соединяющая контейнеры между собой.                                    |

## **4. Основные команды Docker**

### **4.1. Работа с образами**

- **Скачать образ:**
    
    ```sh
    docker pull <image_name>
    ```
    
- **Посмотреть скачанные образы:**
    
    ```sh
    docker images
    ```
    
- **Удалить образ:**
    
    ```sh
    docker rmi <image_id>
    ```
    

### **4.2. Работа с контейнерами**

- **Запустить контейнер (в фоне):**
    
    ```sh
    docker run -d -p 8080:80 nginx
    ```
    
- **Посмотреть работающие контейнеры:**
    
    ```sh
    docker ps
    ```
    
- **Остановить контейнер:**
    
    ```sh
    docker stop <container_id>
    ```
    
- **Удалить контейнер:**
    
    ```sh
    docker rm <container_id>
    ```

## **5. Запуск Linux-машины через Docker**

1. **Скачать образ Ubuntu:**
    
    ```sh
    docker pull ubuntu:latest
    ```
    
2. **Запустить контейнер с Ubuntu в интерактивном режиме:**
    
    ```sh
    docker run -it --name my-linux ubuntu:latest /bin/bash
    ```
    
3. **Выйти из контейнера:**
    
    ```sh
    exit
    ```
    
4. **Запустить контейнер заново:**
    
    ```sh
    docker start -ai my-linux
    ```
    
5. **Удалить контейнер:**
    
    ```sh
    docker rm -f my-linux
    ```

## **6. Развертывание FastAPI-сервера в Docker**

### **6.1. Создание `Dockerfile` для FastAPI**

Создаем `Dockerfile`, который будет собирать контейнер с FastAPI:

```dockerfile
# Используем официальный образ Python
FROM python:3.11

# Устанавливаем рабочую директорию внутри контейнера
WORKDIR /app

# Копируем файлы проекта
COPY . /app

# Устанавливаем зависимости
RUN pip install -r req.txt

# Открываем порт
EXPOSE 8000

# Запускаем сервер
CMD gunicorn src.main:app --workers 1 --worker-class uvicorn.workers.UvicornWorker --bind=0.0.0.0:8000
```

---

### **6.2. Создание FastAPI-приложения**

Создаем файл `main.py`:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "Hello, Docker + FastAPI!"}
```

---

### **6.3. Сборка и запуск контейнера с FastAPI**

1. **Собираем образ:**
    
    ```sh
    docker build -t fastapi-app .
    ```
    
2. **Запускаем контейнер:**
    
    ```sh
    docker run -p 8000:8000 fastapi-app
    ```
    
3. **Проверяем работу сервера:**  
    Открываем в браузере:
    
    ```
    http://localhost:8000
    ```
    
    Или через `curl`:
    
    ```sh
    curl http://localhost:8000
    ```

## **7. Полезные команды Docker**

- **Список запущенных контейнеров:**
    
    ```sh
    docker ps
    ```
    
- **Остановить контейнер:**
    
    ```sh
    docker stop <container_id>
    ```
    
- **Удалить контейнер:**
    
    ```sh
    docker rm <container_id>
    ```
    
- **Удалить образ:**
    
    ```sh
    docker rmi fastapi-app
    ```
    
- **Просмотр логов контейнера:**
    
    ```sh
    docker logs <container_id>
    ```
    
- **Зайти внутрь контейнера:**
    
    ```sh
    docker exec -it <container_id> sh
    ```
    
- **Остановить и удалить все контейнеры:**
    
    ```sh
    docker stop $(docker ps -q) && docker rm $(docker ps -aq)
    ```
