## Как пользоваться

- Начинай с FastAPI, если цель - собрать backend-приложение.
- Для работы с БД смотри связку: SQL -> SQLAlchemy -> Alembic.
- Для защищенных API смотри: авторизация -> JWT -> хеширование паролей.
- Для запуска проекта смотри: Docker -> сервер Ubuntu -> переменные окружения.
