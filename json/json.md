## 🔷 Что такое JSON?

**JSON (JavaScript Object Notation)** — это текстовый формат обмена данными, основанный на синтаксисе JavaScript, но используемый в любом языке программирования (включая Python).

Используется для:

- Обмена данными между клиентом и сервером (например, в REST API),
    
- Хранения конфигураций и настроек,
    
- Сериализации данных (в том числе для Redis, файлов и т.д.).
    

---

## 🔶 Структура JSON

JSON состоит из:

- **Объектов** (`{}`): набор пар `ключ: значение`
    
- **Массивов** (`[]`): список значений
    
- **Простых типов**: строки, числа, `true`, `false`, `null`
    

---

### 🔸 Примеры JSON
```json
{
  "name": "Denis",
  "age": 15,
  "is_student": true,
  "grades": [5, 4, 5],
  "profile": {
    "city": "Irkutsk",
    "school": "Gymnasium #1"
  }
}
```
## 🔷 Правила синтаксиса JSON

- Ключи — **всегда строки в двойных кавычках**
    
- Строки — только в двойных кавычках (`"string"`, не `'string'`)
    
- Нет комментариев!
    
- Нет лишних запятых
    
- Только допустимые типы: `string`, `number`, `boolean`, `null`, `array`, `object`
