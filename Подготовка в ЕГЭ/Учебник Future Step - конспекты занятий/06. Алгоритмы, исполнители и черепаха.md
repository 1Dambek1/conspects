## Черепаха

Для моделирования удобно использовать координаты и команды движения.

Главные идеи:

- поворот меняет направление;
- перемещение меняет координаты;
- повторение команд можно раскрыть циклом;
- если нужна площадь или точки внутри, лучше перейти к геометрическим неравенствам.

## Задание 12

Машина Тьюринга и строковые преобразования.

Типовой подход:

1. Записать начальную строку.
2. Последовательно применять правила.
3. Следить, какое правило выполняется первым.
4. Остановиться только при выполнении условия остановки.

## Python-моделирование строк

```python
s = "111222"

while "111" in s:
    s = s.replace("111", "2", 1)
```

Третий аргумент `1` важен: заменяем только первое вхождение, если алгоритм требует пошаговую замену.

## Частые ошибки

- Заменять сразу все подстроки вместо одной.
- Неправильно понимать порядок правил.
- В задачах с координатами считать границу как внутреннюю точку, когда условие требует строго внутри.

## Разбор задачи 1: строковый исполнитель

Условие в типовом виде:

> Дана строка из единиц. Пока в строке есть `111`, заменить первое вхождение `111` на `2`. Потом заменить первое вхождение `22` на `1`. Что получится?

Код:

```python
s = "111111111"

while "111" in s or "22" in s:
    if "111" in s:
        s = s.replace("111", "2", 1)
    else:
        s = s.replace("22", "1", 1)

print(s)
```

Почему важен третий аргумент `1`:

```python
s.replace("111", "2", 1)
```

Он означает «заменить только первое вхождение». Без него Python заменит все подходящие фрагменты сразу, а в задачах ЕГЭ обычно требуется пошаговое выполнение алгоритма.

## Разбор задачи 2: черепаха без рисования

Условие в типовом виде:

> Черепаха прошла команды и построила многоугольник. Нужно определить, сколько целочисленных точек находится внутри.

Если фигура простая, можно посчитать по координатам.

Пример: прямоугольник от `(0, 0)` до `(10, 5)`.

Точки строго внутри:

```python
count = 0

for x in range(0, 11):
    for y in range(0, 6):
        if 0 < x < 10 and 0 < y < 5:
            count += 1

print(count)
```

Ответ:

```text
9 * 4 = 36
```

Почему не включаем границу:

В условии часто сказано «внутри фигуры», а точки на границе не считаются.

## Разбор задачи 3: моделирование координат

Можно хранить направление как вектор:

```python
x, y = 0, 0
dx, dy = 1, 0

points = [(x, y)]

def right():
    global dx, dy
    dx, dy = dy, -dx

def forward(n):
    global x, y
    x += dx * n
    y += dy * n
    points.append((x, y))

for _ in range(4):
    forward(10)
    right()

print(points)
```

Такой код помогает восстановить вершины фигуры.
