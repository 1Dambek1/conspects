## Задание 22

Диаграмма Ганта показывает выполнение процессов во времени.

Термины:

- процесс - работа с длительностью;
- зависимость - процесс не может начаться до завершения другого;
- раннее начало - минимальный момент старта;
- раннее окончание - старт + длительность.

## Алгоритм

1. Выписать все процессы и длительности.
2. Для независимых процессов старт равен 0.
3. Для зависимых процессов старт равен максимуму окончаний предшественников.
4. Окончание = старт + длительность.
5. Ответ - максимальное окончание всех финальных процессов.

## Частые ошибки

- Складывать длительности всех процессов, хотя часть идет параллельно.
- Брать минимум вместо максимума для нескольких зависимостей.
- Ошибаться на единицу при интервалах времени.

## Разбор задания 18: динамика в таблице

Условие в типовом виде:

> Робот находится в левом верхнем углу таблицы и может двигаться только вправо или вниз. В каждой клетке записано число. Нужно найти максимальную сумму, которую можно набрать по пути в правый нижний угол.

Идея:

В каждой клетке храним лучший результат, с которым можно в нее прийти.

```text
dp[i][j] = value[i][j] + max(dp[i - 1][j], dp[i][j - 1])
```

Python-решение:

```python
table = [
    [5, 1, 3],
    [2, 4, 2],
    [1, 6, 7],
]

n = len(table)
m = len(table[0])

dp = [[0] * m for _ in range(n)]

for i in range(n):
    for j in range(m):
        best_prev = 0
        if i > 0:
            best_prev = max(best_prev, dp[i - 1][j])
        if j > 0:
            best_prev = max(best_prev, dp[i][j - 1])
        dp[i][j] = table[i][j] + best_prev

print(dp[-1][-1])
```

В электронных таблицах делается то же самое формулами: каждая ячейка смотрит на верхнюю и левую.

## Разбор задания 22: процессы и зависимости

Условие в типовом виде:

| Процесс | Длительность | Зависит от |
|---|---:|---|
| A | 4 | - |
| B | 3 | - |
| C | 5 | A |
| D | 2 | A, B |
| E | 6 | C, D |

Решение:

```text
A: старт 0, конец 4
B: старт 0, конец 3
C: старт после A = 4, конец 9
D: старт после A и B = max(4, 3) = 4, конец 6
E: старт после C и D = max(9, 6) = 9, конец 15
```

Ответ:

```text
15
```

Код для проверки:

```python
duration = {
    "A": 4,
    "B": 3,
    "C": 5,
    "D": 2,
    "E": 6,
}

deps = {
    "A": [],
    "B": [],
    "C": ["A"],
    "D": ["A", "B"],
    "E": ["C", "D"],
}

finish = {}

def calc(task):
    if task in finish:
        return finish[task]
    start = 0
    for prev in deps[task]:
        start = max(start, calc(prev))
    finish[task] = start + duration[task]
    return finish[task]

answer = max(calc(task) for task in duration)
print(answer)
```

Такой код полезен, если зависимостей много и легко ошибиться вручную.
