Задания 5 и 14.

## Цель занятия

Научиться переводить числа между системами счисления и решать выражения с основаниями.

## Позиционная система

В позиционной системе значение цифры зависит от ее позиции.

```text
1011_2 = 1*2^3 + 0*2^2 + 1*2^1 + 1*2^0 = 11_10
```

## Перевод из десятичной системы

Алгоритм деления:

1. Делим число на основание.
2. Записываем остаток.
3. Продолжаем делить частное.
4. Ответ читаем снизу вверх.

## Перевод в десятичную систему

Разложить число по степеням основания:

```text
2A_16 = 2*16^1 + 10*16^0 = 42
```

## Быстрые переводы для степеней двойки

- 2 -> 8: группировать биты по 3.
- 2 -> 16: группировать биты по 4.
- 8 -> 2: каждую цифру заменить тремя битами.
- 16 -> 2: каждую цифру заменить четырьмя битами.

## Python

```python
int("2A", 16)
bin(42)
oct(42)
hex(42)
```

Убрать префикс:

```python
bin(42)[2:]
```

## Задание 14

Типовой алгоритм:

2. Найти значение.
3. Перевести в нужную систему.
4. Посчитать требуемые цифры или проверить условие.

## Частые ошибки

- Забывать, что `A = 10`, `B = 11`, `F = 15`.
- Читать остатки сверху вниз.
- Не дописывать нули при группировке двоичного числа.
