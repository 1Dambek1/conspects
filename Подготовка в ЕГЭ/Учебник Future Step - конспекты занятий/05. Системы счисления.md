## Цель занятия

Научиться переводить числа между системами счисления и решать выражения с основаниями.

## Позиционная система

В позиционной системе значение цифры зависит от ее позиции.

```text
1011_2 = 1*2^3 + 0*2^2 + 1*2^1 + 1*2^0 = 11_10
```

## Перевод из десятичной системы

Алгоритм деления:

1. Делим число на основание.
2. Записываем остаток.
3. Продолжаем делить частное.
4. Ответ читаем снизу вверх.

## Перевод в десятичную систему

Разложить число по степеням основания:

```text
2A_16 = 2*16^1 + 10*16^0 = 42
```

## Быстрые переводы для степеней двойки

- 2 -> 8: группировать биты по 3.
- 2 -> 16: группировать биты по 4.
- 8 -> 2: каждую цифру заменить тремя битами.
- 16 -> 2: каждую цифру заменить четырьмя битами.

## Python

```python
int("2A", 16)
bin(42)
oct(42)
hex(42)
```

Убрать префикс:

```python
bin(42)[2:]
```

## Частые ошибки

- Забывать, что `A = 10`, `B = 11`, `F = 15`.
- Читать остатки сверху вниз.
- Не дописывать нули при группировке двоичного числа.

## Разбор задачи 1: найти количество цифр в записи

Условие в типовом виде:

> Значение выражения `4**2024 + 2**2025 - 8` записали в двоичной системе. Сколько единиц в этой записи?

Решение кодом:

```python
n = 4**2024 + 2**2025 - 8
s = bin(n)[2:]
print(s.count("1"))
```

Как думать:

1. `4**2024` можно считать напрямую в Python, большие числа поддерживаются.
2. `bin(n)` возвращает строку вида `0b101010`.
3. `[2:]` отрезает префикс `0b`.
4. `count("1")` считает единицы.

## Разбор задачи 2: подобрать цифру x

Условие в типовом виде:

> Найти цифру `x`, при которой число `12x34_5` делится на 4.

Код:

```python
for x in range(5):
    s = f"12{x}34"
    n = int(s, 5)
    if n % 4 == 0:
        print(x, n)
```

Почему `range(5)`:

В системе счисления с основанием 5 допустимы цифры `0, 1, 2, 3, 4`. Цифры 5 быть не может.

## Универсальная функция перевода из десятичной системы

```python
def to_base(n, base):
    digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    if n == 0:
        return "0"

    res = ""
    while n > 0:
        res = digits[n % base] + res
        n //= base
    return res

print(to_base(42, 2))
print(to_base(42, 16))
```

Эта функция полезна для оснований больше 16, где встроенных `bin`, `oct`, `hex` уже не хватает.
