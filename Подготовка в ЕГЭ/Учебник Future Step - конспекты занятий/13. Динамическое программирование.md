# 13. Динамическое программирование

Источник: https://future-step.ru/tutor/task-23-1/

## К каким заданиям относится

Задание 23.

## Цель занятия

Научиться считать количество программ, которые переводят одно число в другое.

## Идея

Динамическое программирование разбивает большую задачу на маленькие однотипные подзадачи. Результаты подзадач сохраняются и используются дальше.

## Пример

Если команды:

- прибавить 1;
- прибавить 2.

То количество способов попасть в `n`:

```text
ways[n] = ways[n - 1] + ways[n - 2]
```

## Восходящий подход

```python
start = 1
finish = 20

ways = [0] * (finish + 1)
ways[start] = 1

for x in range(start, finish + 1):
    if x + 1 <= finish:
        ways[x + 1] += ways[x]
    if x * 2 <= finish:
        ways[x * 2] += ways[x]

print(ways[finish])
```

## Обязательная точка

Если программа должна пройти через число `k`, ответ считается как произведение:

```text
ways(start -> k) * ways(k -> finish)
```

Если число запрещено, количество способов для него обнуляют.

## Алгоритм задания 23

1. Выписать команды.
2. Определить старт и финиш.
3. Учесть обязательные и запрещенные числа.
4. Посчитать количество способов динамикой.
5. Проверить, что команды не выводят за границы.

## Частые ошибки

- Считать маршруты, которые не проходят обязательную точку.
- Не обнулять запрещенное число.
- Путать направление команд.
- Использовать рекурсию без кеша там, где много повторов.
