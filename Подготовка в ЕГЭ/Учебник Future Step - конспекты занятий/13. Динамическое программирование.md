# 13. Динамическое программирование

Источник: https://future-step.ru/tutor/task-23-1/

## К каким заданиям относится

Задание 23.

## Цель занятия

Научиться считать количество программ, которые переводят одно число в другое.

## Идея

Динамическое программирование разбивает большую задачу на маленькие однотипные подзадачи. Результаты подзадач сохраняются и используются дальше.

## Пример

Если команды:

- прибавить 1;
- прибавить 2.

То количество способов попасть в `n`:

```text
ways[n] = ways[n - 1] + ways[n - 2]
```

## Восходящий подход

```python
start = 1
finish = 20

ways = [0] * (finish + 1)
ways[start] = 1

for x in range(start, finish + 1):
    if x + 1 <= finish:
        ways[x + 1] += ways[x]
    if x * 2 <= finish:
        ways[x * 2] += ways[x]

print(ways[finish])
```

## Обязательная точка

Если программа должна пройти через число `k`, ответ считается как произведение:

```text
ways(start -> k) * ways(k -> finish)
```

Если число запрещено, количество способов для него обнуляют.

## Алгоритм задания 23

1. Выписать команды.
2. Определить старт и финиш.
3. Учесть обязательные и запрещенные числа.
4. Посчитать количество способов динамикой.
5. Проверить, что команды не выводят за границы.

## Частые ошибки

- Считать маршруты, которые не проходят обязательную точку.
- Не обнулять запрещенное число.
- Путать направление команд.
- Использовать рекурсию без кеша там, где много повторов.

## Разбор задачи 1: количество программ

Условие в типовом виде:

> Исполнитель преобразует число. Команды: `+1`, `+2`, `*2`. Сколько программ переводят число 3 в число 20?

Решение динамикой:

```python
start = 3
finish = 20

ways = [0] * (finish + 1)
ways[start] = 1

for x in range(start, finish + 1):
    if x + 1 <= finish:
        ways[x + 1] += ways[x]
    if x + 2 <= finish:
        ways[x + 2] += ways[x]
    if x * 2 <= finish:
        ways[x * 2] += ways[x]

print(ways[finish])
```

Как это работает:

- `ways[x]` - сколько способов попасть в число `x`;
- из каждого числа мы распространяем количество способов в следующие числа;
- если в `x` можно попасть 5 способами, то в `x + 1` добавляется 5 способов.

## Разбор задачи 2: обязательная точка

Условие:

> Сколько программ переводят 3 в 20 и обязательно проходят через 10?

Решаем как два независимых участка:

```python
def count_ways(start, finish):
    ways = [0] * (finish + 1)
    ways[start] = 1

    for x in range(start, finish + 1):
        if x + 1 <= finish:
            ways[x + 1] += ways[x]
        if x + 2 <= finish:
            ways[x + 2] += ways[x]
        if x * 2 <= finish:
            ways[x * 2] += ways[x]

    return ways[finish]

answer = count_ways(3, 10) * count_ways(10, 20)
print(answer)
```

Почему умножаем:

Каждый способ дойти от 3 до 10 можно соединить с каждым способом дойти от 10 до 20.

## Разбор задачи 3: запрещенная точка

Условие:

> Сколько программ переводят 3 в 20 и не проходят через 12?

```python
start = 3
finish = 20
bad = 12

ways = [0] * (finish + 1)
ways[start] = 1

for x in range(start, finish + 1):
    if x == bad:
        ways[x] = 0

    if x + 1 <= finish:
        ways[x + 1] += ways[x]
    if x + 2 <= finish:
        ways[x + 2] += ways[x]
    if x * 2 <= finish:
        ways[x * 2] += ways[x]

print(ways[finish])
```

Запрещенная точка получает 0 способов, как будто туда нельзя попасть.
