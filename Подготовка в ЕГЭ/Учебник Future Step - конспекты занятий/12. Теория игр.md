Источник: https://future-step.ru/tutor/task-19-1/

## К каким заданиям относится

Задания 19-21.

## Цель занятия

Научиться определять выигрышные и проигрышные позиции в играх с двумя игроками.

## Идея

Игроки ходят по очереди. Каждый играет оптимально. Нужно определить, кто может выиграть и за сколько ходов.

## Типы позиций

- `P1` - текущий игрок выигрывает за один ход.
- `V1` - текущий игрок проигрывает, потому что любой ход ведет в `P1`.
- `P2` - текущий игрок может сделать ход в `V1`.
- `V2` - все ходы ведут в позиции, где соперник может выиграть не позже второго хода.

Обозначения могут отличаться, но логика одна: выигрышная позиция - есть ход в проигрышную для соперника.

## Алгоритм

1. Определить условие победы.
2. Выписать допустимые ходы.
3. Найти позиции, из которых можно выиграть за 1 ход.
4. Найти позиции, где все ходы ведут к выигрышу соперника.
5. Продолжать разметку до нужного номера задания.

## Python-шаблон

```python
def moves(s):
    return [s + 1, s * 2]

def game(s):
    if s >= 129:
        return "win"
    next_positions = [game(x) for x in moves(s)]
    if "win" in next_positions:
        return "p1"
    if all(x == "p1" for x in next_positions):
        return "v1"
```

Шаблон нужно адаптировать под конкретную формулировку.

## Частые ошибки

- Считать, что игрок делает случайный ход. В ЕГЭ игроки играют оптимально.
- Для проигрышной позиции проверять «есть плохой ход», а нужно «все ходы плохие».
- Неправильно обрабатывать условие победы.

## Разбор задачи: одна куча

Условие в типовом виде:

> Есть куча из `S` камней. За ход можно прибавить 1 или умножить количество камней на 2. Побеждает игрок, который первым получит не менее 129 камней.

Функция ходов:

```python
def moves(s):
    return [s + 1, s * 2]
```

Функция игры:

```python
def game(s):
    if s >= 129:
        return "END"

    next_states = [game(x) for x in moves(s)]

    if "END" in next_states:
        return "P1"
    if all(x == "P1" for x in next_states):
        return "V1"
    if "V1" in next_states:
        return "P2"
    if all(x == "P1" or x == "P2" for x in next_states):
        return "V2"
```

Как читать обозначения:

- `P1` - текущий игрок может выиграть одним ходом.
- `V1` - текущий игрок проигрывает за один ход соперника, как бы ни сходил.
- `P2` - текущий игрок может перевести игру в `V1`, то есть выиграть вторым ходом.
- `V2` - текущий игрок проигрывает не позже второго хода соперника.

Печатаем позиции:

```python
for s in range(1, 129):
    if game(s) == "P2":
        print(s)
```

## Почему в проигрышных позициях используется `all`

Если позиция проигрышная, это значит:

> Все возможные ходы плохие.

Если есть хотя бы один хороший ход, игрок его выберет, потому что игроки действуют оптимально.

Поэтому:

```python
if all(x == "P1" for x in next_states):
    return "V1"
```

означает: куда бы текущий игрок ни пошел, соперник окажется в позиции выигрыша за 1 ход.

## Две кучи

Если куч две, состояние хранится парой:

```python
def moves(a, b):
    return [
        (a + 1, b),
        (a * 2, b),
        (a, b + 1),
        (a, b * 2),
    ]
```

Условие победы:

```python
if a + b >= 129:
    return "END"
```

Дальше логика такая же.
