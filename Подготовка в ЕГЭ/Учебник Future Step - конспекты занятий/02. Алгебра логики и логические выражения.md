## Базовые операции

| Операция | Смысл | Python |
|---|---|---|
| `НЕ A` | инверсия | `not A` |
| `A И B` | конъюнкция | `A and B` |
| `A ИЛИ B` | дизъюнкция | `A or B` |
| `A -> B` | импликация | `not A or B`, также `A <= B` для bool |
| `A == B` | эквивалентность | `A == B` |

## Приоритет операций

В логике:

1. скобки;
2. отрицание;
3. конъюнкция;
4. дизъюнкция;
5. импликация;
6. эквивалентность.

В Python важно помнить: сравнения вроде `<=` и `==` имеют свой приоритет. Для ЕГЭ безопаснее всегда ставить скобки вокруг импликаций и эквивалентностей.

## Таблица истинности

Для `n` переменных в таблице будет `2 ** n` строк.

```python
from itertools import product

for x, y, z in product([0, 1], repeat=3):
    f = (x and not y) or z
    print(x, y, z, int(f))
```

## Частые ошибки

- Путать импликацию с обычным `if`.
- Записывать `A -> B` как `A or B`.
- Не ставить скобки.
- Использовать `=` вместо `==`.

## Разбор задачи 1: таблица истинности

Условие в типовом виде:

> Дано выражение `(x -> y) and (not z or x)`. Нужно найти строки, где выражение истинно.

Переводим импликацию:

```text
x -> y = not x or y
```

Полный перебор:

```python
from itertools import product

print("x y z f")
for x, y, z in product([0, 1], repeat=3):
    f = ((not x) or y) and ((not z) or x)
    if f:
        print(x, y, z, int(f))
```

Как читать код:

1. `product([0, 1], repeat=3)` перебирает все наборы для `x`, `y`, `z`.
2. `not x or y` - это импликация `x -> y`.
3. `if f:` оставляет только строки, где выражение истинно.

Если в задании дана таблица с пропущенными именами столбцов, нужно сравнить полученные строки с таблицей и подобрать порядок переменных.

## Разбор задачи 2: параметр A в логике

Условие в типовом виде:

> Найти наименьшее целое `A`, при котором выражение истинно для всех `x` от 1 до 100.

Пример выражения:

```text
(x % A == 0) -> (x % 6 == 0)
```

Код:

```python
for A in range(1, 101):
    ok = True
    for x in range(1, 101):
        f = (x % A != 0) or (x % 6 == 0)
        if not f:
            ok = False
            break

    if ok:
        print(A)
        break
```

Почему так:

- импликация `P -> Q` заменена на `not P or Q`;
- `x % A == 0` означает «x делится на A»;
- выражение должно быть истинно для всех `x`, поэтому внутри стоит проверка всех `x`;
- если нашли первое подходящее `A`, выводим и останавливаемся.

## Мини-шпаргалка для Python

```python
# P -> Q
(not P) or Q

# P == Q
P == Q

# P и Q
P and Q

# P или Q
P or Q

# не P
not P
```
