# 09. Рекурсия

Источник: https://future-step.ru/tutor/task-16-1/

## К каким заданиям относится

Задание 16.

## Цель занятия

Понять, как работает рекурсивная функция, и научиться вычислять ее значения.

## Что такое рекурсия

Рекурсия - ситуация, когда функция вызывает саму себя. Она решает задачу через такую же, но меньшую задачу.

Классический пример:

```python
def f(n):
    if n == 1:
        return 1
    return n * f(n - 1)
```

## Обязательные части рекурсии

- База рекурсии - условие остановки.
- Рекурсивный переход - вызов функции с другим аргументом.

Без базы рекурсии функция будет вызывать себя бесконечно, пока Python не остановит программу по пределу рекурсии.

## Стек вызовов

Каждый вызов функции запоминается в стеке. Когда функция доходит до базы, вызовы начинают возвращаться обратно.

## Алгоритм решения задания 16

1. Найти базовые значения.
2. Выписать формулу перехода.
3. Если значения маленькие, посчитать вручную снизу вверх.
4. Если значений много, написать функцию или цикл.
5. При повторных вычислениях использовать кеш.

## Кеширование

```python
from functools import lru_cache

@lru_cache(None)
def f(n):
    if n <= 1:
        return 1
    return f(n - 1) + f(n - 2)
```

## Частые ошибки

- Не заметить, что функция вызывает себя несколько раз.
- Считать сверху вниз и повторять одни и те же вычисления.
- Забыть базовый случай.
- Не учесть, что Python имеет ограничение глубины рекурсии.

## Разбор задачи 1: обычная рекурсия

Условие в типовом виде:

```python
def F(n):
    if n <= 2:
        return 1
    return F(n - 1) + 2 * F(n - 2)
```

> Найти `F(10)`.

Код:

```python
def F(n):
    if n <= 2:
        return 1
    return F(n - 1) + 2 * F(n - 2)

print(F(10))
```

Для маленьких `n` это работает. Для больших значений такая функция может быть медленной, потому что одни и те же значения считаются много раз.

## Разбор задачи 2: рекурсия с кешем

Если нужно найти `F(100)` или больше, добавляем кеш:

```python
from functools import lru_cache

@lru_cache(None)
def F(n):
    if n <= 2:
        return 1
    return F(n - 1) + 2 * F(n - 2)

print(F(100))
```

`lru_cache` запоминает уже посчитанные значения. Если функция снова попросит `F(50)`, Python не будет считать заново.

## Разбор задачи 3: рекурсия с условием по четности

Условие в типовом виде:

```python
def F(n):
    if n < 3:
        return n
    if n % 2 == 0:
        return F(n - 1) + F(n - 2)
    return F(n - 1) - F(n - 2)
```

Код:

```python
from functools import lru_cache

@lru_cache(None)
def F(n):
    if n < 3:
        return n
    if n % 2 == 0:
        return F(n - 1) + F(n - 2)
    return F(n - 1) - F(n - 2)

print(F(30))
```

Как читать:

- сначала всегда проверяем базу;
- потом проверяем ветку для четного `n`;
- если `n` нечетное, выполняется последний `return`.
