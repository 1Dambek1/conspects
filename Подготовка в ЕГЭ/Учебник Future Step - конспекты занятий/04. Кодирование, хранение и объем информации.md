## Кодирование

Компьютер работает с двумя состояниями: 0 и 1. Любой текст, звук, изображение или видео сводятся к последовательности битов.

Минимальные единицы:

- бит - 0 или 1;
- байт - 8 бит;
- Кбайт - 1024 байта;
- Мбайт - 1024 Кбайт;
- Гбайт - 1024 Мбайт.

## Задание 4

Обычно связано с кодированием символов и условием Фано.

Ключевая идея: если ни один код не является началом другого кода, сообщение можно однозначно декодировать.

Алгоритм:

1. Выписать уже известные коды.
2. Проверить, какие варианты запрещены как префиксы.
3. Выбрать код минимальной длины, если это требуется.
4. Проверить однозначность декодирования.

## Задание 7

Часто связано с объемом графики, звука или передачи данных.

Формулы:

```text
объем изображения = ширина * высота * глубина цвета
объем звука = частота * глубина * каналы * время
скорость передачи = объем / время
```

Следи за единицами измерения: биты и байты отличаются в 8 раз.

## Задание 11

Обычно про хранение паролей, идентификаторов, номеров или записей.

Алгоритм:

1. Найти количество возможных символов в алфавите.
2. Определить минимальное число бит на символ: `i = ceil(log2(N))`.
3. Умножить на длину записи.
4. Если записей несколько, умножить на количество.
5. Перевести в байты, Кбайты или Мбайты.

## Частые ошибки

- Делить на 1024 там, где нужно делить на 8.
- Округлять вниз количество бит на символ.
- Забывать про количество каналов в звуке.
- Путать Кбит и Кбайт.

## Разбор задачи 1: пароль и пользователи

Условие в типовом виде:

> Пароль состоит из 12 символов. Используется алфавит из 40 символов. Для хранения каждого пароля выделяется минимальное целое число байт. Сколько байт потребуется для хранения паролей 100 пользователей?

Решение:

1. Находим биты на символ:

```text
2^5 = 32  мало
2^6 = 64  хватает
```

Значит:

```text
1 символ = 6 бит
```

2. На один пароль:

```text
12 * 6 = 72 бита
```

3. Переводим в байты:

```text
72 / 8 = 9 байт
```

4. На 100 пользователей:

```text
9 * 100 = 900 байт
```

Ответ:

```text
900
```

## Разбор задачи 2: нецелое число байт

> Пароль состоит из 11 символов. Алфавит содержит 20 символов. Для каждого пароля выделяется минимальное целое число байт. Сколько байт нужно для 100 пользователей?

1. Биты на символ:

```text
2^4 = 16  мало
2^5 = 32  хватает
```

2. Один пароль:

```text
11 * 5 = 55 бит
```

3. Один пароль в байтах:

```text
55 / 8 = 6.875 -> 7 байт
```

4. Для 100 пользователей:

```text
7 * 100 = 700 байт
```

Главная ловушка: нельзя сначала умножать 55 бит на 100, а потом округлять. В условии сказано, что целое число байт выделяется **для каждого пароля**.

Подробный разбор этой ловушки: [[../Задание 11 - как округлять|Задание 11 - как округлять]].

## Разбор задачи 3: объем изображения

Условие в типовом виде:

> Растровое изображение имеет размер 1024 на 768 пикселей. Используется палитра из 256 цветов. Найти объем изображения в Кбайтах.

Решение:

1. Палитра 256 цветов:

```text
2^8 = 256
```

Значит, один пиксель кодируется 8 битами.

2. Всего пикселей:

```text
1024 * 768 = 786432
```

3. Объем в битах:

```text
786432 * 8
```

4. В байтах:

```text
786432 * 8 / 8 = 786432 байт
```

5. В Кбайтах:

```text
786432 / 1024 = 768 Кбайт
```

Ответ:

```text
768
```

## Разбор задачи 4: звук

Условие в типовом виде:

> Звук записан с частотой 48 кГц, глубиной кодирования 16 бит, стерео. Запись длится 10 секунд. Найти объем в Кбайтах.

Решение:

```text
частота = 48000 измерений в секунду
глубина = 16 бит
каналы = 2
время = 10 секунд
```

Объем:

```text
48000 * 16 * 2 * 10 = 15360000 бит
```

В байтах:

```text
15360000 / 8 = 1920000 байт
```

В Кбайтах:

```text
1920000 / 1024 = 1875 Кбайт
```
