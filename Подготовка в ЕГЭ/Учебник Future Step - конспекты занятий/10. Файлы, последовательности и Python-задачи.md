## Задание 24

Строковые задачи: найти максимальную длину фрагмента, количество подходящих подстрок, последовательность символов.

Базовый подход:

1. Прочитать строку.
2. Заменить неудобные фрагменты или разделить строку.
3. Использовать счетчик текущей длины.
4. Обновлять максимум.

```python
with open("24.txt") as f:
    s = f.readline().strip()

best = cur = 1
for i in range(1, len(s)):
    if s[i] != s[i - 1]:
        cur += 1
    else:
        cur = 1
    best = max(best, cur)

print(best)
```

## Задание 25

Делители и числа.

Шаблон поиска делителей:

```python
def divisors(n):
    res = []
    d = 1
    while d * d <= n:
        if n % d == 0:
            res.append(d)
            if d * d != n:
                res.append(n // d)
        d += 1
    return sorted(res)
```

## Разбор задания 17: последовательные пары

Условие в типовом виде:

> В файле дана последовательность целых чисел. Найти количество пар подряд идущих элементов, у которых сумма кратна 3, и максимальную сумму среди таких пар.

Файл:

```text
10
5
7
8
1
2
```

Код:

```python
with open("17.txt") as f:
    data = list(map(int, f))

count = 0
max_sum = -10**20

for a, b in zip(data, data[1:]):
    s = a + b
    if s % 3 == 0:
        count += 1
        max_sum = max(max_sum, s)

print(count, max_sum)
```

Почему `zip(data, data[1:])`:

- `data` дает элементы с первого;
- `data[1:]` дает элементы со второго;
- вместе получаются пары `(data[0], data[1])`, `(data[1], data[2])` и так далее.

## Разбор задания 17: условие зависит от максимального элемента

Типовая сложность: сначала нужно найти опорное значение.

> Найти пары, в которых хотя бы один элемент больше максимального числа, оканчивающегося на 13.

Код:

```python
with open("17.txt") as f:
    data = list(map(int, f))

mx13 = max(x for x in data if abs(x) % 100 == 13)

ans = []
for a, b in zip(data, data[1:]):
    if a > mx13 or b > mx13:
        ans.append(a + b)

print(len(ans), max(ans))
```

Важно:

- `abs(x) % 100 == 13` корректно работает и для отрицательных чисел;
- сначала ищем `mx13`, потом перебираем пары.

## Разбор задания 24: максимальная длина фрагмента

Условие в типовом виде:

> В строке из букв `A`, `B`, `C` найти максимальную длину фрагмента, где нет двух одинаковых соседних символов.

Код:

```python
with open("24.txt") as f:
    s = f.readline().strip()

best = 1
cur = 1

for i in range(1, len(s)):
    if s[i] != s[i - 1]:
        cur += 1
    else:
        cur = 1
    best = max(best, cur)

print(best)
```

Как думать:

- `cur` - длина текущего подходящего фрагмента;
- если правило продолжает выполняться, увеличиваем `cur`;
- если правило ломается, начинаем новый фрагмент с текущего символа.

## Разбор задания 24: через замену

Условие в типовом виде:

> Найти максимальное количество подряд идущих пар `AB` или `CB`.

Идея: заменить удобные пары на один символ.

```python
with open("24.txt") as f:
    s = f.readline().strip()

s = s.replace("AB", "*")
s = s.replace("CB", "*")

best = 0
cur = 0

for ch in s:
    if ch == "*":
        cur += 1
        best = max(best, cur)
    else:
        cur = 0

print(best)
```

Этот прием работает, когда нужные блоки не пересекаются.

## Разбор задания 25: делители

Условие в типовом виде:

> Найти первые 5 чисел больше 1 000 000, у которых ровно 3 нетривиальных делителя.

Шаблон:

```python
def divisors(n):
    res = []
    d = 2
    while d * d <= n:
        if n % d == 0:
            res.append(d)
            if d * d != n:
                res.append(n // d)
        d += 1
    return sorted(res)

found = 0
n = 1_000_001

while found < 5:
    divs = divisors(n)
    if len(divs) == 3:
        print(n, max(divs))
        found += 1
    n += 1
```

Нетривиальные делители - это делители, кроме 1 и самого числа.

## Разбор задания 26: жадный отбор

Условие в типовом виде:

> Есть диск объемом `S` и файлы разных размеров. Нужно записать максимальное количество файлов, а затем найти размер самого большого файла среди выбранных.

Код:

```python
with open("26.txt") as f:
    S, N = map(int, f.readline().split())
    files = [int(f.readline()) for _ in range(N)]

files.sort()

chosen = []
used = 0

for size in files:
    if used + size <= S:
        chosen.append(size)
        used += size

print(len(chosen), max(chosen))
```

Почему сортируем по возрастанию:

Чтобы взять как можно больше файлов, сначала выгодно брать маленькие.

Но в некоторых задачах 26 после этого нужно заменить последний выбранный файл на максимально возможный. Тогда добавляется второй проход по невыбранным файлам.
