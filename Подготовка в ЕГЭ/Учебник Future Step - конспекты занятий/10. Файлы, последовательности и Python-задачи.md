## Пары и тройки последовательных элементов

```python
for a, b in zip(data, data[1:]):
    ...

for a, b, c in zip(data, data[1:], data[2:]):
    ...
```

## Задание 24

Строковые задачи: найти максимальную длину фрагмента, количество подходящих подстрок, последовательность символов.

Базовый подход:

1. Прочитать строку.
2. Заменить неудобные фрагменты или разделить строку.
3. Использовать счетчик текущей длины.
4. Обновлять максимум.

```python
with open("24.txt") as f:
    s = f.readline().strip()

best = cur = 1
for i in range(1, len(s)):
    if s[i] != s[i - 1]:
        cur += 1
    else:
        cur = 1
    best = max(best, cur)

print(best)
```

## Задание 25

Делители и числа.

Шаблон поиска делителей:

```python
def divisors(n):
    res = []
    d = 1
    while d * d <= n:
        if n % d == 0:
            res.append(d)
            if d * d != n:
                res.append(n // d)
        d += 1
    return sorted(res)
```

## Частые ошибки

- Оставлять `\n` в строке.
- Перебирать пары через неправильный диапазон.
- Путать последовательные пары с любыми парами.
- В задании 26 сортировать не по тому признаку.
