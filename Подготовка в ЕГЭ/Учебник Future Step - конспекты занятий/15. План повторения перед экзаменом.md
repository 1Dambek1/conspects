# 15. План повторения перед экзаменом

Источник общей структуры: https://future-step.ru/tutor/

## Неделя 1: база

- Задание 1: таблицы, графы, матрицы.
- Задание 2: логика и таблицы истинности.
- Задание 3: базы данных.
- Задания 4, 7, 11: кодирование и объем информации.
- Задания 5, 14: системы счисления.

## Неделя 2: Python и алгоритмы

- Задание 8: комбинаторика, `itertools`.
- Задание 12: строковые алгоритмы.
- Задание 13: сети и `ipaddress`.
- Задание 16: рекурсия.
- Задание 17: последовательности чисел.

## Неделя 3: сложные задачи

- Задания 19-21: теория игр.
- Задание 23: динамическое программирование.
- Задание 24: строки.
- Задание 25: делители.
- Задание 26: файловая задача.
- Задание 27: кластеризация.

## Неделя 4: экзаменационный режим

- Решать полные варианты.
- Ограничивать время.
- После каждого варианта разбирать ошибки.
- Вести отдельный список типовых ошибок.

## Чек-лист перед экзаменом

- [ ] Умею читать файлы в Python.
- [ ] Умею работать с `map`, `zip`, `product`, `permutations`.
- [ ] Помню перевод систем счисления.
- [ ] Помню формулы объема информации.
- [ ] Умею строить таблицу истинности.
- [ ] Умею решать игры через выигрышные и проигрышные позиции.
- [ ] Умею решать задание 23 динамикой.
- [ ] Умею находить делители числа.
- [ ] Умею обрабатывать строки.
- [ ] Умею читать точки и искать медоид.

## Лист ошибок

После каждого варианта записывать:

- номер задания;
- причина ошибки;
- правильный способ решения;
- что повторить.
