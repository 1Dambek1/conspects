## Основные случаи

Размещения с повторениями: каждая позиция выбирается независимо.

```python
from itertools import product

for word in product("ABC", repeat=4):
    s = "".join(word)
```

Перестановки без повторений:

```python
from itertools import permutations

for word in permutations("ABC"):
    s = "".join(word)
```

## Алгоритм решения

1. Определить алфавит.
2. Понять, можно ли повторять символы.
3. Выбрать `product` или `permutations`.
4. Перебрать варианты.
5. Проверить ограничения из условия.
6. Посчитать подходящие.

## Пример шаблона

```python
from itertools import product

count = 0
for item in product("ABCDE", repeat=5):
    word = "".join(item)
    if word.count("A") == 1 and "EE" not in word:
        count += 1

print(count)
```

## Частые ошибки

- Использовать `permutations`, когда буквы могут повторяться.
- Забыть склеить кортеж в строку через `"".join(...)`.
- Неправильно понимать фразу «не более», «не менее», «ровно».

## Разбор задачи 1: слова с повторениями

Условие в типовом виде:

> Сколько существует 5-буквенных слов из букв `АБВГ`, в которых буква `А` встречается ровно один раз?

Код:

```python
from itertools import product

alphabet = "АБВГ"
count = 0

for letters in product(alphabet, repeat=5):
    word = "".join(letters)
    if word.count("А") == 1:
        count += 1

print(count)
```

Почему `product`, а не `permutations`:

В условии не сказано, что буквы нельзя повторять. Значит, на каждой позиции можно выбрать любую букву, поэтому используется декартово произведение.

## Разбор задачи 2: слова без повторений

Условие в типовом виде:

> Сколько 4-буквенных слов можно составить из букв `АБВГД`, если буквы не повторяются и слово не начинается с `А`?

Код:

```python
from itertools import permutations

count = 0

for letters in permutations("АБВГД", 4):
    word = "".join(letters)
    if word[0] != "А":
        count += 1

print(count)
```

Почему `permutations`:

Буквы не повторяются, значит каждая буква может быть использована только один раз.

## Разбор задачи 3: номер слова в списке

Условие в типовом виде:

> Все 4-буквенные слова из букв `АБВ`, составленные в алфавитном порядке, пронумерованы с 1. Под каким номером стоит слово `БАВА`?

Код:

```python
from itertools import product

for number, letters in enumerate(product("АБВ", repeat=4), start=1):
    word = "".join(letters)
    if word == "БАВА":
        print(number)
        break
```

`enumerate(..., start=1)` нужен, потому что в задаче нумерация начинается с 1, а не с 0.
