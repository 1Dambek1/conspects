## К каким заданиям относится

Задание 27.

## Цель занятия

Научиться читать точки из файла, делить их на кластеры и находить центры кластеров по условию.

## Что изменилось в современных вариантах

В учебнике Future Step задание 27 описано как задача на кластеризацию данных. Обычно в файле лежат точки на плоскости: `x y`.

Общий план:

1. Прочитать точки.
2. Разделить точки на кластеры.
3. В каждом кластере найти центр или медоид по условию.
4. Посчитать требуемые средние координаты.

## Чтение точек

```python
points = []

with open("27_A.txt") as f:
    for line in f:
        x, y = line.replace(",", ".").split()
        points.append((float(x), float(y)))
```

## Кластеризация прямыми

Если кластеры визуально отделяются линиями, можно задать условия:

```python
cluster1 = []
cluster2 = []

for x, y in points:
    if y > x + 2:
        cluster1.append((x, y))
    else:
        cluster2.append((x, y))
```

## Медоид

Медоид - точка кластера, для которой сумма расстояний до всех остальных точек минимальна.

```python
def dist(p1, p2):
    return ((p1[0] - p2[0]) ** 2 + (p1[1] - p2[1]) ** 2) ** 0.5

def medoid(cluster):
    best_point = None
    best_sum = 10**100
    for p in cluster:
        s = sum(dist(p, q) for q in cluster)
        if s < best_sum:
            best_sum = s
            best_point = p
    return best_point
```

## k-средних и DBSCAN

В учебнике выделены три подхода:

- разделение прямыми;
- k-средних;
- DBSCAN.

Для экзамена важно не название метода, а надежность: кластеризация должна правильно разделить точки из файла.

## Частые ошибки

- Не заменить запятую на точку в дробных числах.
- Перепутать `x` и `y`.
- Считать среднее всех точек вместо медоида, если в условии нужен центр по сумме расстояний.
- Проверить только файл A и забыть файл B.
