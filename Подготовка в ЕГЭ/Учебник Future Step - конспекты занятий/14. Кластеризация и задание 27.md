Задание 27.

## Цель занятия

Научиться читать точки из файла, делить их на кластеры и находить центры кластеров по условию.

## Что изменилось в современных вариантах

В учебнике Future Step задание 27 описано как задача на кластеризацию данных. Обычно в файле лежат точки на плоскости: `x y`.

Общий план:

1. Прочитать точки.
2. Разделить точки на кластеры.
3. В каждом кластере найти центр или медоид по условию.
4. Посчитать требуемые средние координаты.

## Чтение точек

```python
points = []

with open("27_A.txt") as f:
    for line in f:
        x, y = line.replace(",", ".").split()
        points.append((float(x), float(y)))
```

## Кластеризация прямыми

Если кластеры визуально отделяются линиями, можно задать условия:

```python
cluster1 = []
cluster2 = []

for x, y in points:
    if y > x + 2:
        cluster1.append((x, y))
    else:
        cluster2.append((x, y))
```

## Медоид

Медоид - точка кластера, для которой сумма расстояний до всех остальных точек минимальна.

```python
def dist(p1, p2):
    return ((p1[0] - p2[0]) ** 2 + (p1[1] - p2[1]) ** 2) ** 0.5

def medoid(cluster):
    best_point = None
    best_sum = 10**100
    for p in cluster:
        s = sum(dist(p, q) for q in cluster)
        if s < best_sum:
            best_sum = s
            best_point = p
    return best_point
```

## k-средних и DBSCAN

В учебнике выделены три подхода:

- разделение прямыми;
- k-средних;
- DBSCAN.

Для экзамена важно не название метода, а надежность: кластеризация должна правильно разделить точки из файла.

## Частые ошибки

- Не заменить запятую на точку в дробных числах.
- Перепутать `x` и `y`.
- Считать среднее всех точек вместо медоида, если в условии нужен центр по сумме расстояний.
- Проверить только файл A и забыть файл B.

## Разбор задачи 1: ручное разделение кластерами

Условие в типовом виде:

> В файле находятся точки двух кластеров. Кластеры разделяются прямой `y = x`. Найти центры кластеров и вычислить средние координаты центров.

Чтение:

```python
points = []

with open("27_A.txt") as f:
    for line in f:
        x, y = line.replace(",", ".").split()
        points.append((float(x), float(y)))
```

Разделение:

```python
cluster1 = []
cluster2 = []

for x, y in points:
    if y > x:
        cluster1.append((x, y))
    else:
        cluster2.append((x, y))
```

Медоид:

```python
def dist(p, q):
    return ((p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2) ** 0.5

def medoid(cluster):
    best = None
    best_sum = 10**100

    for p in cluster:
        s = 0
        for q in cluster:
            s += dist(p, q)

        if s < best_sum:
            best_sum = s
            best = p

    return best
```

Ответ:

```python
c1 = medoid(cluster1)
c2 = medoid(cluster2)

px = (c1[0] + c2[0]) / 2
py = (c1[1] + c2[1]) / 2

print(int(px * 10000), int(py * 10000))
```

## Разбор задачи 2: кластеризация через расстояние

Если кластеры не разделяются очевидной прямой, можно собирать соседние точки по расстоянию.

Идея:

- берем точку;
- ищем все точки рядом с ней;
- затем ищем точки рядом с найденными;
- так получаем связный кластер.

Простой вариант:

```python
def dist(p, q):
    return ((p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2) ** 0.5

def get_cluster(start, points, used, eps):
    cluster = []
    stack = [start]
    used.add(start)

    while stack:
        p = stack.pop()
        cluster.append(p)

        for q in points:
            if q not in used and dist(p, q) <= eps:
                used.add(q)
                stack.append(q)

    return cluster

used = set()
clusters = []
eps = 1.5

for p in points:
    if p not in used:
        clusters.append(get_cluster(p, points, used, eps))

print([len(c) for c in clusters])
```

`eps` подбирается по рисунку или по расстояниям между точками.

## Как проверять ответ

1. Количество кластеров должно совпадать с условием.
2. Размеры кластеров должны выглядеть разумно: не должно быть кластера из одной точки, если на рисунке такого нет.
3. Центры должны визуально лежать внутри своих кластеров.
4. Нужно решить оба файла: `A` и `B`.
