## Базы данных

База данных хранит данные в организованном виде. В реляционном подходе данные разделяются на таблицы.

Термины:

- таблица - набор однотипных записей;
- запись - строка таблицы;
- поле - столбец таблицы;
- ключ - уникальный идентификатор записи;
- связь - отношение между таблицами через ключи.

## Почему не одна большая таблица

Одна огромная таблица быстро приводит к ошибкам:

- данные повторяются;
- сложно исправлять опечатки;
- трудно искать связи;
- появляются противоречия.

Решение - разделять сущности: ученики отдельно, предметы отдельно, оценки отдельно.

## Разбор задачи 1: две связанные таблицы

Условие в типовом виде:

Есть таблица `Ученики`:

| id | имя | класс |
|---:|---|---|
| 1 | Анна | 10А |
| 2 | Борис | 10Б |
| 3 | Вера | 10А |

И таблица `Оценки`:

| student_id | предмет | балл |
|---:|---|---:|
| 1 | информатика | 90 |
| 2 | информатика | 75 |
| 3 | информатика | 88 |

> Найти средний балл учеников из класса 10А.

Решение:

1. В таблице `Ученики` выбираем id учеников из 10А: `1`, `3`.
2. В таблице `Оценки` берем строки с `student_id` 1 и 3.
3. Считаем среднее:

```text
(90 + 88) / 2 = 89
```

Код для проверки:

```python
students = [
    {"id": 1, "name": "Анна", "class": "10А"},
    {"id": 2, "name": "Борис", "class": "10Б"},
    {"id": 3, "name": "Вера", "class": "10А"},
]

marks = [
    {"student_id": 1, "subject": "информатика", "score": 90},
    {"student_id": 2, "subject": "информатика", "score": 75},
    {"student_id": 3, "subject": "информатика", "score": 88},
]

ids = {s["id"] for s in students if s["class"] == "10А"}
scores = [m["score"] for m in marks if m["student_id"] in ids]

print(sum(scores) / len(scores))
```

## Разбор задачи 2: поиск в тексте

Условие в типовом виде:

> В тексте найти количество слов, которые начинаются на `про` и заканчиваются на `а`.

Код:

```python
text = "программа проверка процессора проба задача"

count = 0
for word in text.split():
    word = word.strip(".,!?;:").lower()
    if word.startswith("про") and word.endswith("а"):
        count += 1

print(count)
```

Что важно:

- `split()` разбивает текст на слова по пробелам;
- `strip(".,!?;:")` убирает знаки препинания по краям;
- `lower()` убирает проблему с регистром.
