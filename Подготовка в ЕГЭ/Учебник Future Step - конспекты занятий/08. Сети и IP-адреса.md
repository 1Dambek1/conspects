Задание 13.

## Цель занятия

Научиться работать с IP-адресами, масками и сетями.

## Базовые понятия

- IP-адрес IPv4 состоит из 4 байтов.
- Маска определяет, какая часть адреса относится к сети.
- Адрес сети получается побитовым `AND` между IP и маской.
- В одной сети у адресов совпадает сетевая часть.

## Модуль `ipaddress`

```python
from ipaddress import ip_network

net = ip_network("192.168.1.0/24")

for ip in net:
    print(ip)
```

Если сеть задается адресом хоста, можно использовать:

```python
net = ip_network("192.168.1.15/24", strict=False)
```

## Алгоритм задания 13

1. Определить IP и маску.
2. Перевести маску в префикс или наоборот.
3. Найти адрес сети.
4. Перебрать адреса сети, если нужно посчитать подходящие.
5. Проверить условие по двоичной записи, октетам или количеству единиц.

## Проверка двоичной записи

```python
bits = bin(int(ip))[2:].zfill(32)
ones = bits.count("1")
```

## Частые ошибки

- Забывать `strict=False`.
- Считать адрес сети и broadcast обычными узлами, если условие говорит только о хостах.
- Проверять десятичную запись вместо двоичной.

## Разбор задачи 1: посчитать адреса по условию

Условие в типовом виде:

> Для сети `192.168.32.160/27` определить количество IP-адресов, в двоичной записи которых количество единиц четно.

Код:

```python
from ipaddress import ip_network

net = ip_network("192.168.32.160/27")
count = 0

for ip in net:
    bits = bin(int(ip))[2:].zfill(32)
    if bits.count("1") % 2 == 0:
        count += 1

print(count)
```

Как работает:

1. `ip_network(...)` создает объект сети.
2. `for ip in net` перебирает все адреса сети.
3. `int(ip)` превращает IP-адрес в число.
4. `bin(...)[2:].zfill(32)` дает 32-битную двоичную запись.
5. `count("1")` считает единицы.

## Разбор задачи 2: если дан адрес узла

Условие в типовом виде:

> Дан IP-адрес `192.168.12.37` и маска `/26`. Нужно определить адрес сети.

Код:

```python
from ipaddress import ip_network

net = ip_network("192.168.12.37/26", strict=False)
print(net.network_address)
```

Почему нужен `strict=False`:

`192.168.12.37` - это адрес узла, а не обязательно адрес сети. Без `strict=False` Python может выдать ошибку.

## Хосты без адреса сети и broadcast

Если в условии сказано «адреса компьютеров» или «узлы сети», часто нужно исключить адрес сети и broadcast.

```python
from ipaddress import ip_network

net = ip_network("10.0.0.0/29")

for ip in net.hosts():
    print(ip)
```

`net.hosts()` перебирает только рабочие адреса узлов.
