## Цель занятия

Научиться работать с IP-адресами, масками и сетями.

## Базовые понятия

- IP-адрес IPv4 состоит из 4 байтов.
- Маска определяет, какая часть адреса относится к сети.
- Адрес сети получается побитовым `AND` между IP и маской.
- В одной сети у адресов совпадает сетевая часть.

## Модуль `ipaddress`

```python
from ipaddress import ip_network

net = ip_network("192.168.1.0/24")

for ip in net:
    print(ip)
```

Если сеть задается адресом хоста, можно использовать:

```python
net = ip_network("192.168.1.15/24", strict=False)
```

## Алгоритм задания 13

1. Определить IP и маску.
2. Перевести маску в префикс или наоборот.
3. Найти адрес сети.
4. Перебрать адреса сети, если нужно посчитать подходящие.
5. Проверить условие по двоичной записи, октетам или количеству единиц.

## Проверка двоичной записи

```python
bits = bin(int(ip))[2:].zfill(32)
ones = bits.count("1")
```

## Частые ошибки

- Забывать `strict=False`.
- Считать адрес сети и broadcast обычными узлами, если условие говорит только о хостах.
- Проверять десятичную запись вместо двоичной.
