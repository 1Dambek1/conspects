Ещё с древних времён известен простой метод шифрования сообщений — шифр Цезаря. Он основан на том, что каждая буква шифруемого сообщения циклически сдвигается на 3 позиции в алфавите («a» заменяется на «d», «b» — на «e», ..., «z» — на «c»). Например, слово «caesar» в зашифрованном виде выглядит как «fdhvdu».

В XVI веке появилась более сложная модификация этого шифра — шифр Виженера — который считался невзламываемым на протяжении столетий. В шифре Виженера каждая буква сдвигается уже не на 3, а на разное количество позиций в алфавите. Величина сдвига определяется вспомогательным словом — ключом.

Пусть мы шифруем слово «vigenere» при помощи ключа «ace». Прежде всего нужно повторить ключ столько раз, чтобы его длина совпала с длиной шифруемого слова — в нашем случае получится «aceaceac». Теперь каждая буква шифруемого слова сдвигается на количество позиций в алфавите, равное номеру соответствующей буквы ключа:

- Первая буква ключа — «a», поэтому первая буква слова сдвигается на 1 позицию;
    
- Вторая буква ключа — «c», поэтому вторая буква слова сдвигается на 3 позиции;
    
- Третья буква ключа — «e», поэтому третья буква слова сдвигается на 5 позиций;
    
- Четвёртая буква ключа — «a», поэтому четвёртая буква слова сдвигается на 1 позицию, и так далее.
    

В конце концов слово «vigenere» превратится в «wllfqjsh».

Составьте функцию _vigenere_decode(cipher, key)_, которая будет расшифровывать текст _cipher_, закодированный шифром Виженера с ключом _key_.

## Формат ввода

Функция должна принимать строки _cipher_ и _key_ (_1 ≤ len(cipher) ≤ 1000_, _1 ≤ len(key) ≤ 30_), состоящие из строчных латинских букв, — соответственно зашифрованный текст и ключ.

## Формат вывода

Функция должна возвращать строку — расшифрованный текст.

### Пример 1
Ввод
cipher = 'wllfqjsh'
key = 'ace'
print(vigenere_decode(cipher, key))

Вывод
vigenere

Пример 2
Ввод
cipher = 'snhogojtfiiwemm'
key = 'python'
print(vigenere_decode(cipher, key))

Вывод
congratulations

```python
def vigenere_decode(cipher, key):
    # Строка, в которую будем постепенно добавлять
    # расшифрованные символы.
    result = ""

    # Перебираем все символы шифра.
    # i — номер символа.
    # letter — текущая буква зашифрованного текста.
    for i, letter in enumerate(cipher):

        # Определяем соответствующую букву ключа.
        # Если ключ закончился,
        # начинаем использовать его сначала.
        key_letter = key[i % len(key)]

        # Вычисляем величину сдвига.
        # ord('a') = 97.
        # Для буквы 'a' получаем сдвиг 1,
        # для 'b' — 2,
        # ...
        # для 'z' — 26.
        shift = ord(key_letter) - ord("a") + 1

        # Переводим текущую букву в число от 0 до 25.
        code = ord(letter) - ord("a")

        # Выполняем обратный сдвиг.
        # Оператор % 26 обеспечивает переход
        # через начало алфавита.
        code = (code - shift) % 26

        # Преобразуем число обратно в букву
        # и добавляем её к ответу.
        result += chr(code + ord("a"))

    # Возвращаем расшифрованный текст.
    return result
```
