Призрак тут же собрался превращаться в большую черную собаку – этот трюк принес ему заслуженную славу и явился причиной неизлечимого слабоумия дядюшки лорда Кентервиля, достопочтенного Томаса Хортона. Но звук приближающихся шагов заставил его отказаться от этого коварного намерения, так что ему пришлось удовольствоваться тем, что он стал слабо фосфоресцировать, и он исчез, испустив леденящий душу кладбищенский стон.  

Напишите программу по учету превращений привидения за 19 и 20 век.

## Формат ввода

В файле **transformation.json**, доступном вашему решению, находится список словарей с ключами: в кого превратился, год, размер, цвет, количество зрителей (_turned into, year, size, color, number of viewers_).

## Формат вывода

В файл **accounting.csv** запишите в порядке возрастания года, в случае одинакового – в алфавитном порядке, записи превращений за 19 и 20 век. Заголовки файла (разделитель точка с запятой):

_turned_into;size;number_of_viewers;year_

### Пример 1
Ввод
[
 {
   "turned into": "dog", "year": 1564,
   "size": "big", "color": "black",
   "number of viewers": 5
 },
 {
   "turned into": "raven", "year": 1844,
   "size": "huge", "color": "black",
   "number of viewers": 3
 },
 {
   "turned into": "ghost", "year": 1966,
   "size": "cool", "color": "white",
   "number of viewers": 1
 }
]

Вывод
turned_into;size;number_of_viewers;year
raven;huge;3;1844
ghost;cool;1;1966

Пример 2
Ввод
[
 {
   "turned into": "cloud", "year": 1820,
   "size": "small", "color": "sky",
   "number of viewers": 1
 },
 {
   "turned into": "skeleton", "year": 1914,
   "size": "large", "color": "bone",
   "number of viewers": 3
 },
 {
   "turned into": "golf ball", "year": 1918,
   "size": "little", "color": "beige",
   "number of viewers": 3
 }
]
Вывод
turned_into;size;number_of_viewers;year
cloud;small;1;1820
skeleton;large;3;1914
golf ball;little;3;1918

```python
# Импортируем модуль json.
# Он позволяет читать данные из файлов формата JSON.
import json

# Импортируем модуль csv.
# Он предназначен для чтения и записи файлов формата CSV.
import csv


# Открываем файл transformation.json для чтения.
# encoding="utf-8" позволяет корректно работать с русскими символами.
with open("transformation.json", encoding="utf-8") as file:

    # Загружаем содержимое файла.
    # В результате переменная data будет содержать список словарей.
    data = json.load(file)


# Создаем пустой список.
# В него будем добавлять только те записи,
# которые относятся к XIX и XX векам.
result = []


# Перебираем все словари из списка.
for item in data:

    # Проверяем год превращения.
    # XIX век — с 1801 по 1900 год.
    # XX век — с 1901 по 2000 год.
    if 1801 <= item["year"] <= 2000:

        # Если год подходит,
        # добавляем словарь в новый список.
        result.append(item)


# Сортируем список.
#
# key определяет правило сортировки.
#
# Сначала записи сортируются по году.
# Если годы совпадают,
# то дополнительно сортируются
# по названию превращения.
result.sort(key=lambda x: (x["year"], x["turned into"]))


# Открываем файл accounting.csv для записи.
#
# "w" — режим записи.
#
# newline="" нужен, чтобы между строками
# не появлялись пустые строки
# (особенно в операционной системе Windows).
#
# encoding="utf-8" позволяет корректно
# записывать текст.
with open("accounting.csv", "w", newline="", encoding="utf-8") as file:

    # Создаем объект writer.
    # delimiter=";" означает,
    # что столбцы будут разделяться точкой с запятой.
    writer = csv.writer(file, delimiter=";")


    # Записываем строку заголовков.
    writer.writerow([
        "turned_into",
        "size",
        "number_of_viewers",
        "year"
    ])


    # Перебираем все подходящие записи.
    for item in result:

        # Записываем одну строку CSV-файла.
        #
        # Обратите внимание:
        # в JSON используются ключи
        # "turned into"
        # "number of viewers"
        #
        # а в заголовке CSV вместо пробелов стоят символы "_".
        writer.writerow([
            item["turned into"],
            item["size"],
            item["number of viewers"],
            item["year"]
        ])
```
