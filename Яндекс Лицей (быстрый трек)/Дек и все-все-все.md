Программист Евгений изучает различные структуры данных и решил погрузиться в теорию двусвязных очередей, которые можно построить на базе списков Python.

Напомним, что двусвязная очередь (дек) — это такая структура данных, в которой элементы можно добавлять и в начало, и в конец. Удалять их тоже можно как из конца, так и из начала.

Евгений предлагает Вам реализовать класс Deque, моделирующий работу двусвязной очереди.

Однако Евгений не ищет лёгких путей и хочет усложнить Вам работу: **дек может быть инициализирован** различным числом элементов.

Например,

s = Deque(1, 2, 3, 4, 5) — создаёт дек [1<->2<->3<->4<->5], а  
  
s = Deque(1, 2, 3) — [1<->2<->3].

Но все же есть гарантия того, что для инициализации передаётся хотя бы один параметр.

**Класс Deque реализует следующие методы:**

a p p e n d ( s e l f , ∗ v a l u e s ) append(self,∗values) — добавляет переданные значения последовательно в дек справа (как минимум одно).

l a p p e n d ( s e l f , ∗ v a l u e s ) lappend(self,∗values) — добавляет переданные значения в дек слева (как минимум одно).

c o p y ( s e l f ) copy(self) — создаёт копию данного дэка, то есть возвращает новый дек.

p o p ( s e l f ) pop(self) — вытаскивает и возвращает элемент с правой вершины дека, при этом этот элемент из дека пропадает. Если дек пустой, то возвращает None.

l p o p ( s e l f ) lpop(self) — вытаскивает и возвращает элемент с левой вершины дека, при этом этот элемент из дека пропадает. Если дек пустой, то возвращает None.

n e x t ( s e l f ) next(self) — возвращает новый дек, начиная с элемента справа от текущего.

l n e x t ( s e l f ) lnext(self) — возвращает новый дек, начиная с элемента слева от текущего.

**Операторы и встроенные функции:**

d e q u e 1 + d e q u e 2 deque1+deque2 — Сложение деков. В результате создаётся новый дек.

d e q u e 1 = = d e q u e 2 deque1==deque2 — Проверяет деки на равенство всех элементов. Причём достаточно, если элементы будут совпадать в прямом или обратном порядке. То есть [1<->2<->3<->4<->5] == [5<->4<->3<->2<->1].

d e q u e > > N deque>>N — создаёт новый дек без первых N (вышедших) элементов.

d e q u e < < N deque<<N — создаёт новый дек без последних N (вышедших) элементов.

s t r ( d e q u e ) str(deque) — приводит дек к строке вида [sn<-> ...<->s3<->s2<->s1]. Пустой или ошибочный дек представляется как [].

n e x t ( d e q u e ) next(deque) — действие, аналогичное методу next().

```python
class Deque:

    # Конструктор класса.
    # Вызывается автоматически при создании объекта.
    #
    # *values означает, что можно передать
    # любое количество элементов.
    #
    # Например:
    # Deque(1)
    # Deque(1, 2, 3)
    # Deque(5, 7, 9, 10)
    def __init__(self, *values):

        # Сохраняем все переданные элементы
        # в обычный список Python.
        self.data = list(values)


    # Добавляет элементы в конец дека.
    #
    # append(4)
    # append(4, 5)
    # append(4, 5, 6)
    def append(self, *values):

        # Метод extend() добавляет
        # каждый элемент по отдельности.
        self.data.extend(values)


    # Добавляет элементы в начало дека.
    #
    # Например:
    #
    # [3,4]
    # lappend(1,2)
    #
    # станет
    #
    # [1,2,3,4]
    def lappend(self, *values):

        # Создаем новый список:
        # сначала новые элементы,
        # затем старое содержимое дека.
        self.data = list(values) + self.data


    # Создает полную копию дека.
    #
    # Возвращается новый объект,
    # а не ссылка на существующий.
    def copy(self):

        # *self.data распаковывает список.
        #
        # Если self.data = [1,2,3],
        #
        # то получится
        #
        # Deque(1,2,3)
        return Deque(*self.data)


    # Удаляет последний элемент дека
    # и возвращает его.
    #
    # Если дек пуст,
    # возвращает None.
    def pop(self):

        # Если список не пустой.
        if self.data:

            # Метод pop() списка
            # удаляет последний элемент.
            return self.data.pop()

        return None


    # Удаляет первый элемент дека.
    def lpop(self):

        if self.data:

            # pop(0) удаляет элемент
            # с индексом 0.
            return self.data.pop(0)

        return None


    # Возвращает новый дек,
    # начиная со второго элемента.
    #
    # Исходный дек не изменяется.
    #
    # [1,2,3,4]
    #
    # станет
    #
    # [2,3,4]
    def next(self):

        # Если элементов меньше двух,
        # вернуть пустой дек.
        if len(self.data) <= 1:
            return Deque()

        # self.data[1:]
        # означает взять список,
        # начиная с элемента под индексом 1.
        return Deque(*self.data[1:])


    # Возвращает новый дек
    # без последнего элемента.
    #
    # [1,2,3,4]
    #
    # станет
    #
    # [1,2,3]
    def lnext(self):

        if len(self.data) <= 1:
            return Deque()

        # self.data[:-1]
        # означает взять все элементы,
        # кроме последнего.
        return Deque(*self.data[:-1])


    # Позволяет использовать
    #
    # next(deque)
    #
    # вместо
    #
    # deque.next()
    def __next__(self):

        return self.next()


    # Оператор сложения.
    #
    # deque1 + deque2
    #
    # создает новый дек.
    def __add__(self, other):

        # Складываем два списка
        # и создаем новый дек.
        return Deque(*(self.data + other.data))


    # Проверка на равенство.
    #
    # Работает оператор ==
    def __eq__(self, other):

        # Деки считаются равными,
        # если:
        #
        # элементы совпадают
        #
        # или
        #
        # совпадают в обратном порядке.
        return (
            self.data == other.data
            or
            self.data == other.data[::-1]
        )


    # Оператор >>
    #
    # deque >> N
    #
    # удаляет первые N элементов.
    def __rshift__(self, n):

        # self.data[n:]
        # берет элементы,
        # начиная с индекса n.
        return Deque(*self.data[n:])


    # Оператор <<
    #
    # deque << N
    #
    # удаляет последние N элементов.
    def __lshift__(self, n):

        # Если нужно удалить 0 элементов,
        # возвращаем копию.
        if n == 0:
            return self.copy()

        # self.data[:-n]
        # берет все элементы,
        # кроме последних n.
        return Deque(*self.data[:-n])


    # Преобразование объекта в строку.
    #
    # Работает функция print().
    def __str__(self):

        # Если дек пуст.
        if not self.data:
            return "[]"

        # Соединяем элементы строкой "<->"
        #
        # Например:
        #
        # [1,2,3]
        #
        # станет
        #
        # 1<->2<->3
        return "[" + "<->".join(map(str, self.data)) + "]"
```
