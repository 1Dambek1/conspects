Конечно, это не подлинный рецепт Ухты-Ухты соуса, который готовят только в тщательно контролируемых условиях и готовность которого определяется близостью к точке разложения со взрывом. Когда в буфетной Незримого Университета обнаружили бутыль с соусом пятилетний выдержки, все крыло здания было эвакуировано на целых два дня, пока соус не съели во время ликвидационного обеда.  

Напишите программу, которая выберет правильные даты для ликвидационного обеда. Это не может быть понедельник и не может быть день, сумма дня и месяца которого делится на _n_.

## Формат ввода

Вводится начальная дата в виде _DD.MM.YYYY_ и число _n_.

## Формат вывода

Вывести два ближайших подряд идущих дня, начиная со следующего после введенного, удовлетворяющих указанным условиям. Формат вывода показан в примерах. Такие дни точно есть.

### Пример 1

Ввод
21.02.2021
13

Вывод
25 February 21
26 February 21

Пример 2

Ввод
02.05.2021
4

Вывод
04 May 21
05 May 21

```python
# Импортируем класс datetime для работы с датами
# и класс timedelta для прибавления дней.
from datetime import datetime, timedelta

# Считываем дату в формате ДД.ММ.ГГГГ
# Например: 21.02.2021
# Метод strptime преобразует строку в объект даты.
date = datetime.strptime(input(), "%d.%m.%Y")

# Считываем число n.
n = int(input())

# Переходим к следующему дню,
# так как по условию нужно искать даты,
# начиная со следующего после введённого дня.
date += timedelta(days=1)

# Будем последовательно проверять все даты,
# пока не найдём две соседние подходящие.
while True:

    # Первый день предполагаемой пары.
    first = date

    # Второй день пары — следующий календарный день.
    second = date + timedelta(days=1)

    # Проверяем сразу четыре условия:
    #
    # 1. Первый день не является понедельником.
    # weekday() возвращает:
    # 0 - понедельник
    # 1 - вторник
    # ...
    # 6 - воскресенье
    #
    # 2. Сумма номера дня и номера месяца
    # не должна делиться на n.
    #
    # 3. Второй день также не должен быть понедельником.
    #
    # 4. Для второго дня сумма дня и месяца
    # также не должна делиться на n.
    if (
        first.weekday() != 0
        and (first.day + first.month) % n != 0
        and second.weekday() != 0
        and (second.day + second.month) % n != 0
    ):

        # Если обе даты удовлетворяют условиям,
        # выводим их в требуемом формате:
        # день месяц год(2 цифры)
        print(first.strftime("%d %B %y"))
        print(second.strftime("%d %B %y"))

        # Завершаем цикл.
        break

    # Если хотя бы одно условие нарушено,
    # начинаем поиск со следующего дня.
    date += timedelta(days=1)
```
