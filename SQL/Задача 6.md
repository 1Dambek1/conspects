https://leetcode.com/problems/the-latest-login-in-2020/
```sql
SELECT user_id, MAX(time_stamp) as last_stamp
FROM Logins
WHERE time_stamp >= '2020-01-01' AND time_stamp < '2021-01-01'
GROUP BY user_id;
```
Объяснение шагов:

1. Ограничение даты `time_stamp` для выборки записей только за 2020 год:
    

```sql
WHERE time_stamp >= '2020-01-01' AND time_stamp < '2021-01-01'
```

Использование функции `MAX(time_stamp)` для нахождения максимальной даты логина для каждого пользователя:

```sql
SELECT user_id, MAX(time_stamp) as last_stamp
```

- Группировка результатов по `user_id` с помощью `GROUP BY user_id`.
