Для решения данной задачи вам потребуется использовать оператор `UPDATE` и логические операторы для проверки текущего значения в столбце и соответствующего изменения на противоположное. Без использования промежуточной временной таблицы, это можно сделать следующим образом:

```sql
UPDATE Salary
SET sex = CASE
    WHEN sex = 'f' THEN 'm'
    WHEN sex = 'm' THEN 'f'
END;
```

Рассмотрим каждый элемент этого запроса:

1. **Оператор `UPDATE`**:
    

```sql
UPDATE Salary
```

- Обновление происходит в таблице `Salary`.
- **Проверка текущего значения столбца `sex`**:
    

```sql
WHEN sex = 'f' THEN 'm'
WHEN sex = 'm' THEN 'f'
```

- Используются две условные конструкции `WHEN` для проверки текущего значения в столбце `sex`. Если значение равно `'f'`, оно меняется на `'m'`, и наоборот, если значение равно `'m'`, оно меняется на `'f'`.
- **Замена значения**:
    

```sql
SET sex = CASE
   ...
END;
```

1. Значение в столбце `sex` обновляется в зависимости от результата проверки в `CASE`.

Этот запрос изменит все значения в столбце `sex` таким образом, что каждое значение `'f'` станет `'m'`, а каждое значение `'m'` станет `'f'`.
