Для получения количества уникальных `lead_id` и `partner_id` для каждой комбинации `date_id` и `make_name`, можно использовать подзапросы и объединение таблиц. Приведенный ниже запрос выполняет данную задачу:

```sql
SELECT
    date_id,
    make_name,
    COUNT(DISTINCT lead_id) AS unique_leads,
    COUNT(DISTINCT partner_id) AS unique_partners
FROM DailySales
GROUP BY 1, 2;
```
