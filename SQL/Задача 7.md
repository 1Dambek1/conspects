```sql
SELECT
    employee_id,
    CASE
        WHEN MOD(employee_id, 2) = 1 AND name NOT LIKE 'M%' THEN salary
        ELSE 0
    END AS bonus
FROM
    Employees
ORDER BY
	employee_id;
```
Объяснение шагов:

1. **Проверка на нечетность ID**: `MOD(employee_id, 2) = 1` проверяет, является ли идентификатор сотрудника нечетным числом.
2. **Проверка начала имени**: `name NOT LIKE 'M%'` проверяет, начинается ли имя сотрудника с буквы 'M'.
3. **Условие CASE**: Устанавливает бонус в зависимости от результата проверок. Если сотрудник имеет нечетный идентификатор и его имя не начинается с 'M', бонус равен его зарплате. Во всех остальных случаях бонус равен нулю.
4. **Вывод результата**: Результат сортируется по идентификатору сотрудника.
